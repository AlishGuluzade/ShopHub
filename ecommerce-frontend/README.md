# ShopHub - E-Commerce Marketplace

A full-stack e-commerce marketplace platform built with FastAPI, React, and Docker.

## Live Demo
Coming soon...

## Tech Stack

**Backend:**
- Python / FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
- Docker & Docker Compose

**Frontend:**
- React.js
- CSS3

## Features

- JWT Authentication with role-based access (Superadmin, Admin, Customer)
- Shopping cart with quantity management
- Order management with delivery status tracking
- Marketplace system - users can list their own products
- Admin approval system for new product listings
- Product search and category filtering
- Admin dashboard for managing orders, users, and pending products
- Fully dockerized with Docker Compose

## Getting Started

**Prerequisites:** Docker Desktop

**Installation:**

```bash
git clone https://github.com/AlishGuluzade/ShopHub.git
cd ShopHub
docker compose up -d
```
